# Konfeti

Konfeti est une application d'invitations d'événements fun et joyeuse, inspirée de Partiful.

Le principe : créer une invitation de soirée belle et fun en 60 secondes, l'envoyer par WhatsApp ou SMS, et laisser les invités répondre en quelques secondes. Ensuite, tout se passe dans Konfeti : chat du groupe, qui vient, qui amène quoi, cagnotte, infos pratiques. L'objectif est que les invités vivent tout l'événement dans l'application, sans jamais devoir retourner sur WhatsApp ou Facebook.

Lancement sur le marché francophone (Belgique et France), avec une architecture pensée dès le départ pour accueillir d'autres langues.

Projet privé, en développement.
